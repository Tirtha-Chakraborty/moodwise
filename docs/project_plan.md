# Project plan

The overall plan for Moodwise across versions V1 to V4. Change this file only when the plan itself changes.

## Goal

The user types a phrase (a feeling, lyric, word) and gets back songs, quotes, and later books and movies that match the mood. The project is also how the author learns backend engineering in Go, at roughly 3-4 hours a week.

## Versions

### V1 (current)

**Goal:** match a phrase to songs and quotes.

**Features:**

- Go
- Fixed mood buckets, classified by an LLM API
- Songs and quotes only
- Hand-curated flat JSON dataset
